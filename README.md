# Nothing News

Минималистичное русскоязычное news-приложение в визуальном языке текущего Glyph/Nothing-проекта.

## Что уже есть

- мобильный интерфейс по концепту: главный экран, категории, живая лента, карточка новости, контекст/источник, дайджест и спокойный режим;
- реальные RSS-источники через локальный Node.js backend;
- автоматическое обновление каждые 5 минут;
- дедупликация похожих заголовков;
- базовая категоризация;
- поиск;
- демо-лента на случай, если backend или источники недоступны;
- PWA shell.

## Запуск на постоянно включённом компьютере

Нужен Node.js 20+.

```bash
npm install
npm start
```

Открой:

```
http://localhost:8787
```

Чтобы открыть с телефона в той же Wi‑Fi сети, узнай локальный IP компьютера и открой:

```
http://IP-КОМПЬЮТЕРА:8787
```

Например `http://192.168.1.50:8787`.

## Источники

Они лежат в `config/sources.json`. Сейчас добавлены несколько RSS-лент. Любой источник можно удалить или добавить без изменений frontend-кода.

Если конкретный RSS временно не отвечает, backend продолжает работать с остальными.

## API

- `GET /api/news?limit=30`
- `GET /api/news?category=Технологии`
- `GET /api/news?q=OpenAI`
- `POST /api/refresh`
- `GET /health`

## Следующий этап

Сейчас backend собирает заголовки и descriptions из источников. Следующий слой — AI news desk:

1. объединение нескольких публикаций об одном событии в один сюжет;
2. нормализация/перевод на русский;
3. краткий summary;
4. блок «Почему это важно»;
5. несколько источников внутри одной карточки;
6. персонализация тем.

API-ключи не должны попадать в frontend или GitHub — их нужно хранить только на сервере в `.env`.
