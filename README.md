# Nothing News

Минималистичное русскоязычное news-приложение в визуальном языке Glyph/Nothing-проекта.

## Сейчас всё работает без твоего компьютера

Новости обновляются в GitHub Actions по расписанию, после чего статический сайт публикуется в GitHub Pages.

То есть больше не нужно:

- ставить Node.js;
- держать терминал открытым;
- запускать `npm start`;
- знать IP компьютера.

После включения GitHub Pages приложение открывается обычной ссылкой.

## Что уже есть

- главный экран;
- категории;
- живая лента;
- карточка новости;
- источник и контекст;
- дайджест;
- спокойный режим;
- поиск;
- мобильный интерфейс;
- автоматический сбор RSS;
- базовая дедупликация;
- базовая категоризация;
- обновление примерно каждые 10 минут.

## Как обновляются новости

GitHub Actions запускает:

`scripts/update_news.py`

Скрипт читает `config/sources.json`, собирает RSS и формирует:

`public/data/news.json`

После этого содержимое папки `public` автоматически публикуется в GitHub Pages.

## Источники

Источники лежат в:

`config/sources.json`

Их можно добавлять и удалять без изменений frontend-кода.

## Локальный backend

`server.js` оставлен как дополнительный вариант для разработки, но для обычного использования он больше не нужен.
