# Personal UI Experiments

This repository currently contains two separate native/display projects.

## Tactile Camera

Native iPhone camera built in SwiftUI + AVFoundation.

Location:

`TactileCamera.xcodeproj`

Includes live camera preview, tactile controls, Core Haptics, generated click/shutter sounds, filters, manual exposure/focus/white-balance controls and local photo saving.

## Glyph Weather TV

Samsung Tizen TV ambient weather display.

Location:

`tizen-tv/`

Targeted at Samsung **UE55AU7100UXRU (AU7100, 2021)** with a Tizen 6.0 web-app configuration.

Includes animated weather, dot-matrix temperature, forecast, clock/date and full Samsung remote navigation.

See:

`tizen-tv/README.md`
